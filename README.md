# Ensiklopedia Shorof

Aplikasi statis untuk belajar ilmu Shorof dan tashrif, lengkap dengan:

- Pengantar ilmu Shorof dan Nahwu
- Tashrif istilahi dan lughawi
- Mesin tashrif otomatis
- Kalkulator tashrif
- Kuis interaktif
- Referensi kitab

Dibuat sebagai aplikasi web statis yang dapat dibuka di desktop maupun HP.
